# Project-Pokémon-App
This is the public repository for Project Pokémon App

## Project Description:
This project aims to make a working script to be used for a database that contains all created Pokémon cards using TCG's live card collection API. The purpose of the database is to 
be a basis for any kind of Pokémon app a user may want to make with this project functioning as the backend.

## Requirements:
- VSCode (or preferred code editor)
-   https://code.visualstudio.com/download?_exp_download=fb315fc982
- PostgreSQL (or preferred database)
-   https://www.postgresql.org/download/
-   use all default settings, but remember the password as it will be used for the client
- Node
- https://nodejs.org/en/download
- Npm
- typically installed with node
- verify with node -v and npm -v
- if not installed
-   sudo apt install npm

## Set Up Steps:
1. download TransferFile.js
2. Create database in PostgreSQL named pokedata (change line 5 database name if different name used)
3. run script to have all card information displayed to console
